## About

This repository holds the setup for a personal portfolio. It currently contains a freshly bootstrapped `create-next-app` project (App Router, JavaScript, Tailwind CSS v4) in the `app/` folder. The home page is still the default Next.js starter page, and no portfolio content has been added yet.

## Tech Stack

- Next.js 15 (App Router) with Turbopack for development
- React 19
- Tailwind CSS v4
- ESLint (`eslint-config-next`)

## Project Structure

```
app/
  src/app/
    layout.js     # Root layout (Geist fonts)
    page.js       # Home page
    globals.css
  public/         # Static assets
  package.json
```

## Getting Started

**Prerequisites:** Node.js 18.18+ and npm.

```bash
cd app
npm install
npm run dev       # http://localhost:3000
```

Other scripts: `npm run build`, `npm start`, `npm run lint`.
